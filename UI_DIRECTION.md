# LeadOS UI Direction

## Overall Feel

LeadOS should feel like a modern B2B SaaS dashboard.

It should be clean, practical, and trustworthy.

The user should feel like they are using serious agency software, not a flashy landing-page template.

## Inspiration

Use the product feel of:

- Linear
- Attio
- HubSpot CRM
- Stripe Dashboard
- GoHighLevel agency dashboard, but cleaner and simpler

## Visual Style

- Clean white/neutral interface
- Subtle borders
- Generous spacing
- Minimal shadows
- Crisp typography
- Sidebar navigation
- Topbar with tenant switcher
- Cards for stats
- Tables for contacts
- Kanban board for pipeline
- Forms with clear labels and validation
- Badges for status and tags
- Practical empty states

## Layout

Authenticated app layout should include:

- left sidebar
- topbar
- tenant switcher
- main content area
- page header
- primary action button per page

## Navigation

Main tenant navigation:

- Dashboard
- Contacts
- Pipeline
- Forms
- Inbox
- Calendar
- Automations
- Settings

Agency navigation:

- Blueprints
- Billing

Admin navigation:

- Admin dashboard

## Components

Build reusable components where practical:

- AppSidebar
- Topbar
- TenantSwitcher
- PageHeader
- StatCard
- EmptyState
- ContactForm
- OpportunityForm
- PipelineBoard
- PipelineColumn
- OpportunityCard
- BlueprintCard

## Empty States

Every major empty page should tell the user:

- what is missing
- why it matters
- what to do next

Example:

No contacts yet. Capture a lead from a form or add your first contact manually.

## Tone

Use direct, agency-friendly language.

Good labels:

- New lead
- Booked
- Won
- Lost
- Install blueprint
- Create client workspace
- Capture leads
- Follow-up system

Avoid overly technical terms in the UI where possible.

## Do Not Overdo

Do not spend Phase 1 on:

- fancy animations
- complex themes
- unnecessary gradients
- complicated dashboards
- mobile-perfect polish

Prioritize working CRM functionality and clean UX.
